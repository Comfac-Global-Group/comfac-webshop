== CRUD Events ==

'''Item Events''' (<code>webshop/webshop/crud_events/item/</code>):

- <code>update_website_item.execute</code> - Sync Item → Website Item
- <code>invalidate_item_variants_cache.execute</code> - Clear variant cache on save/rename
- <code>validate_duplicate_website_item.execute</code> - Prevent duplicate web items

'''Quotation Events''' (<code>webshop/webshop/crud_events/quotation/</code>):

- <code>validate_shopping_cart_items.execute</code> - Validate cart items on save

'''Price List Events''' (<code>webshop/webshop/crud_events/price_list/</code>):

- <code>check_impact_on_cart.execute</code> - Check if price list changes affect cart

'''Tax Rule Events''' (<code>webshop/webshop/crud_events/tax_rule/</code>):

- <code>validate_use_for_cart.execute</code> - Validate tax rules for cart usage
